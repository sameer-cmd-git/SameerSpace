# Sameer Space — Portfolio

This repository contains the source code for my personal portfolio website, built with React and Vite.

## Live site

https://sameer-cmd-git.github.io/SameerSpace/

## What this project includes

- Responsive portfolio layout
- About, skills, projects, and contact sections
- Modern animated UI
- GitHub Pages deployment

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

## Build for production

```bash
cd portfolio
npm run build
```

## Deployment

The site is deployed on GitHub Pages using GitHub Actions.
